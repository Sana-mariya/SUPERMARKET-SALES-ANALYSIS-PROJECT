# SUPERMARKET-SALES-ANALYSIS-PROJECT
Supermarket Sales Data Analytics Dashboard

Project Overview

The Supermarket Sales Data Analytics Dashboard is a Microsoft Excel-based data analytics project designed to analyze supermarket sales performance and generate meaningful business insights. This project focuses on understanding sales trends, product line performance, branch-wise revenue, customer ratings, and profitability through data cleaning, data analysis, PivotTables, KPI cards, and interactive dashboards.

The main objective of this project is to transform raw supermarket sales data into a structured, interactive, and easy-to-understand dashboard that supports data-driven business decisions.

Project Objectives

- Analyze overall supermarket sales and revenue performance.
- Identify the highest-performing branches and product lines.
- Understand monthly sales trends and variations.
- Evaluate cost of goods sold, gross income, and profit percentage.
- Analyze product quantities sold and customer ratings.
- Create an interactive dashboard for quick business performance monitoring.

Project Workflow

1. Raw Data

The original supermarket sales dataset was imported into Excel for initial inspection and preparation.

2. Data Cleaning

The dataset was reviewed and cleaned to improve data quality and consistency. Duplicate records were checked, and the cleaned data was organized into a structured Excel table for analysis.

3. Data Preparation

Additional fields, including Month, Month Number, and Order Size, were created to support monthly analysis and order categorization.

4. Data Analysis

Excel formulas, PivotTables, and summary calculations were used to analyze sales, quantity sold, cost of goods sold, gross income, average customer rating, branch performance, and product line performance.

5. Pivot Analysis

PivotTables were created to summarize key business metrics and compare performance across different categories, branches, cities, and months.

6. Dashboard Development

An interactive Excel dashboard was designed with KPI cards, charts, and slicers to provide a clear overview of supermarket performance. Users can filter the results by month, branch, city, and product line to explore different aspects of the data.
